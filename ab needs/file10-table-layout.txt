TABLE LAYOUT RULES (list screens) - sticky columns and alignment
==============================================================================

Standard rule (script + styles at the end of app/templates/base.html)
----------------------------------------------------------------------
1. In the template, put the identifying columns leftmost, in this order when present:
       date, farmer / name, village / stockyard / industry, grain
2. Set data-sticky-left="N" on the <table> (N = how many leftmost columns are pinned; default 2).
3. The table sits directly inside a <div class="overflow-x-auto">.
4. Alignment (always, scrolling or not): the first N columns are LEFT-aligned, every other column
   (including the Edit / Open / Pay button column) is RIGHT-aligned.
5. Pinning (only when the table is wider than its box): the first N columns stay in view, the rest
   scroll sideways. The button column is NOT pinned. If the pinned columns would take more than 60%
   of the width (phones) nothing is pinned.
6. Tables with fewer than 4 columns, or with data-no-sticky, are left alone.
7. A new column that is a key to the row goes inside the first N; anything else goes after them.
   Adding a screen = follow steps 1-3, nothing else.

Edit buttons and business years (see file9-database.txt)
----------------------------------------------------------------------
The Edit button of a row is shown only if can_edit_year(user, year) is true: owner, and the year is
one of the last 3 business years. The accountant never sees Edit buttons.

Toolbar filters are remembered (village, grain, date)
----------------------------------------------------------------------
The filters chosen in the top bar stay chosen when you move to another page. They are kept in a
browser-session cookie (toolbar_filters) and change only when you pick another value, choose "All",
press "Filter on" (clear all), or log out / log in again. A filter greyed out on a page keeps its stored
value for the next page. Code: app/core/toolbar_state.py, applied in app/main.py (load_grains).
