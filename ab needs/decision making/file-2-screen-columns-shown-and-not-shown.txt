DECISION MAKING 2 - OUTPUT SCREEN COLUMNS: SHOWN AND NOT SHOWN, PER TABLE
==============================================================================
For each table: the columns that appear on an output screen (list, tab, page, statement or printed receipt) with the screen and the column heading
they appear under, and the columns that appear on NO output screen (they are only on New / Edit forms, or used inside the application).
Foreign-key columns (..._id) are shown on screen as the name they point to. Columns that come from another table are listed with that table.
Screen columns that are worked out (totals, balances, status) are not table columns and are listed in file 3 and at the end of this file.
